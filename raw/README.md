# raw/ — captured source material

This folder holds things you have captured and want to keep: meeting transcripts, voice notes, articles, observations, interview notes. Anything that records what was said, read, or seen.

Two rules:

1. **Raw is never edited.** Once a file lands here, leave it. It is a record of a moment, and that moment does not get rewritten later. If something in it turns out to be wrong, write a new note and link back to the old one rather than changing the original.
2. **Name files by date and source:** `YYYY-MM-DD-source-slug.md`, for example `2026-05-29-call-with-acme.md` or `2026-05-12-article-ai-adoption.md`. The date is when you captured it, not when it happened.

What does not go here: documents you are still actively editing (those are working files), and anything you will rewrite as your thinking changes (that belongs in `wiki/`).

The short version: `raw/` is what happened. `wiki/` is what you make of it.
